# Памятка для студента: Работа со стендом Creative Center

**Дисциплина:** «Оптимизация веб-приложений» · НГУЭУ · группа 9-ИС303  
**Эталонный сайт:** https://129-101-112-157.sslip.io/  
**Ваш персональный стенд:** `https://129-101-112-157.sslip.io/students/studentXX/` (где `XX` — ваш номер, например `01`, `02`, `15`).

---

## 1. Начало работы (локально на вашем компьютере)

На вашем компьютере **не требуется** устанавливать Python, Node.js или базы данных. Нужен только **Git**, текстовый редактор (VS Code, Notepad++ и т.д.) и браузер (Chrome / Яндекс Браузер).

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/nsuem-projects/creative-center.git
   cd creative-center
   ```
2. Переключитесь в вашу закреплённую ветку (например, для студента 01):
   ```bash
   git checkout student-01
   ```
   *(Если ветка ещё не создана локально: `git checkout -b student-01`)*

---

## 2. Внесение изменений и публикация

1. Редактируйте HTML, CSS или JS файлы локально.
2. Сохраните изменения и отправьте их в GitHub:
   ```bash
   git add .
   git commit -m "Оптимизация стилей и скриптов"
   git push origin student-01
   ```
3. Откройте ваш адрес в браузере:
   **`https://129-101-112-157.sslip.io/students/student01/`**
   *(Изменения публикуются автоматически в течение нескольких секунд).*

---

## 3. Исследование в DevTools (Network и Console)

1. Откройте ваш сайт в браузере и нажмите **F12** (или `Ctrl+Shift+I`).
2. Перейдите во вкладку **Network** («Сеть»).
3. Обязательно поставьте галочку **Disable cache** («Отключить кэш»).
4. Нажмите `Ctrl+R` (или `F5`) для перезагрузки страницы.

### На что обратить внимание:
* **Задержка расписания (schedule.html):**  
  Найдите запрос `/api/schedule`. Во вкладке **Timing** колонка **Waiting for server response (TTFB)** покажет реальное сетевое ожидание около 3 секунд.
* **Тяжёлые ресурсы (workshops.html, blog.html):**  
  Найдите файлы `legacy-gallery.js` (~2 МБ) и `editorial-archive.css` (~1.2 МБ). Обратите внимание на колонку **Size** / **Transfer**.
* **Отсутствующие ресурсы (намеренные 404):**  
  Обратите внимание на строки со статусом `404 Not Found` (`catalog-tags.json`, `map-theme.css` и др.).
* **Консоль (Console):**  
  Команда `CreativeCenterTraining.mode` покажет режим `'server'`.

---

## 4. Автономный режим (без интернета)
Если у вас нет доступа к интернету, вы можете просто дважды щёлкнуть по файлу `index.html` на своём компьютере. Сайт откроется в протоколе `file://` и продолжит работать локально (в этом режиме задержка расписания эмулируется таймером JavaScript).
