## Автономный режим — 8 октября 2026

- Node VM без DOM проверил адаптер: file://-ветка не вызывает fetch, повторяет featured три раза, получает 10 занятий, обновляет расписание после таймера ≥2900 ms, отклоняет неизвестный ID. Это проверка логики, не запуск браузера file://.
- Проверены три отдельных fetch статического featured JSON, резервные данные при HTTP 404, серверный режим без дополнительного JS-таймера.
- Настоящий обновлённый server.py: runtime-mode.js возвращает server, /api/schedule отвечает через 3,00 секунды, featured возвращает три занятия.
- Все 10 типов страниц открыты во встроенном Chromium-браузере на server.py и статическом HTTP по подпапке /creative-center/. Заголовки и динамический контент доступны, горизонтального переполнения нет.
- verify.py на обновлённом сервере 8000 прошёл: страницы, локальные ссылки, четыре намеренных 404, API, задержка, размеры тяжёлых ресурсов.
- Синтаксис main.js и training-api.js проверен node --check.

Ограничения: browser security policy запрещает file:// во встроенном браузере; обход не выполнялся. Chrome и Яндекс Браузер через двойной щелчок не проверены непосредственно. На настоящем GitHub Pages новая версия пока не опубликована; проверен эквивалентный статический HTTP с подпапкой проекта, но это не подтверждение deployment. После загрузки на GitHub требуется окончательная проверка опубликованной версии.

Ручная проверка без установки программ: распаковать архив → открыть index.html в Chrome/Яндекс → проверить меню, фильтры, workshop.html?id=2, teacher.html?id=2, карту, выбор сертификата и обновление расписания через 3 секунды; Console не должна содержать необработанных ошибок кроме сообщений браузера о намеренно отсутствующих файлах и внешних ресурсах. Для file:// ожидается журнал вызовов в памяти, а не HTTP 404 или API-запросы Network.
