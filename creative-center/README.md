# Центр творческих мастерских

Учебный многостраничный сайт для курса «Оптимизация веб-приложений». Чистые HTML5, CSS3 и vanilla JavaScript. Весь контент вымышленный; локальные SVG-иллюстрации и WebP-портреты входят в проект. Формы проверяют поля и показывают результат локально, ничего не отправляют, не принимают оплату и не создают запись.

## Запуск

Нужен Python 3.9 или новее. Пакеты, npm и сборка не нужны.

Откройте терминал в папке проекта и выполните:

```sh
python server.py
```

На Windows можно использовать `py server.py`. Откройте http://masterskaya.localhost:8000/ . Адрес проверен во встроенном браузере Codex. Если браузер не распознаёт имя, запасной адрес: http://127.0.0.1:8000/ . Системные настройки менять не нужно. Другой порт: `python server.py --port 8080`. Остановка: Ctrl+C.

Обычный статический сервер также открывает сайт: `python -m http.server 8000`. Однако API на нём вернёт дополнительные 404, задержка не воспроизведётся. Для полной лабораторной используйте **server.py**. Через file:// лабораторная не работает.

## Страницы

* index.html — главная, направления, занятия, преподаватели, событие, подарок и журнал.
* workshops.html — каталог из 10 занятий и фильтры; query `?category=Керамика` выбирает направление.
* workshop.html?id=1…10 — занятие, программа, мастер, стоимость, даты и учебная запись.
* teachers.html — преподаватели; teacher.html?id=1…3 — профиль и занятия.
* schedule.html — расписание и свободные места.
* certificates.html — номиналы и учебная форма заказа.
* blog.html — журнал; article.html?id=1…3 — статьи.
* contacts.html — контакты, схема карты и форма.

## Учебные проблемы

| Страница | Проблема | Как реализована | Что искать в Network |
|---|---|---|---|
| /index.html | Повторные API-запросы | Три отдельных fetch `/api/featured-workshops`; cache: no-store и серверный Cache-Control: no-store исключают переиспользование ответа | Три строки с одним URL, статус 200; фильтр Fetch/XHR |
| /index.html | Сторонний шрифт | CSS fonts.googleapis.com и, при успешной загрузке, шрифт fonts.gstatic.com; локальный fallback Arial | Domain: два домена Google, тип stylesheet/font |
| /index.html | Сторонний CSS | normalize.min.css с cdnjs.cloudflare.com | Domain: cdnjs.cloudflare.com |
| /workshops.html | Тяжёлый JS | js/legacy-gallery.js: историческая таблица 16 000 палитр, около 2 МБ, реально подключена defer, без сжатия | Size: ресурс значительно больше main.js |
| /workshops.html | Много отдельных запросов | 10 отдельных GET /api/workshops/1…10 без объединения | Fetch/XHR: 10 строк одного локального домена |
| /workshops.html | 404 JSON | GET /assets/data/catalog-tags.json; несуществующий файл, ошибка обработана | Status: 404 |
| /schedule.html | Медленный API | GET /api/schedule: time.sleep(3) в отдельном потоке; уже показанное расписание остаётся доступным | Time/Waterfall: около 3000 ms, преимущественно Waiting (TTFB) |
| /schedule.html | Много запросов | 6 отдельных GET /api/workshops/1…6 | Fetch/XHR: 6 обращений одного домена |
| /blog.html | Тяжёлый CSS | css/editorial-archive.css: 15 000 правил старых печатных тем, около 1,2 МБ | Size: stylesheet больше styles.css |
| /blog.html | 404 JS | Динамически подключён /js/journal-recommendations.js, отсутствует; журнал не зависит от него | Status: 404, тип script |
| /contacts.html | 404 изображение | new Image() запрашивает /assets/images/entrance-evening.webp; отсутствующий дополнительный ракурс не участвует в разметке | Status: 404, тип image |
| /contacts.html | 404 CSS | Дополнительный /css/map-theme.css отсутствует; основная схема оформлена styles.css | Status: 404, тип stylesheet |
| /contacts.html | Сторонний ресурс | CSS Leaflet с cdn.jsdelivr.net; карта — локальная SVG/CSS-подобная схема, работоспособность не зависит от CDN | Domain: cdn.jsdelivr.net |

Иных намеренных дефектов нет. Большие таблицы и печатные темы — специально избыточные устаревшие ресурсы; они не нужны для основного интерфейса. Основные CSS, JS и изображения локальные. Сторонние ресурсы не являются трекерами; формы не передают им пользовательские данные. Браузер отправляет обычные технические данные запроса на CDN. При отсутствии интернета внешние запросы могут завершиться сетевой ошибкой, сайт работает с локальным шрифтом и схемой карты.

403 и 500 требуют серверной логики/прав доступа; здесь они не имитируются. Намеренные ошибки статических файлов — настоящие HTTP 404. Сервер слушает только loopback, подходит для локальной лабораторной, а не публичного production.

## Проверка в Chrome DevTools

Откройте Network **до** перезагрузки. Включите Disable cache; отключите Preserve log для проверки одной страницы. Переходите по страницам и сортируйте Status, Time, Size; добавьте столбец Domain через контекстное меню заголовков. Фильтр `/api/` выделяет запросы API. Повторы видны даже без Disable cache, потому что задан no-store. Вкладка Timing медленного запроса показывает ожидание сервера. При включённом throttling общая задержка будет больше трёх секунд.

Контент отображается до завершения API и при его отказе; ошибки фоновых fetch перехвачены. Пользовательский интерфейс не маркирует учебные сетевые дефекты. В консоли ожидаемы сообщения браузера о четырёх отсутствующих файлах и JSON, а также об отказах внешних CDN при отсутствии сети.

## Автоматическая проверка

При запущенном server.py выполните `python verify.py`. Скрипт проверяет все страницы, локальные ссылки и ресурсы (за исключением точного списка намеренных 404), ответы API, повторные обращения, задержку и размеры. Проверка взаимодействий и реальных записей Network дополнительно требует браузера. Результат выполнения сохранён в VERIFICATION.md.

## Обновлённое оформление

Все шрифты без засечек: Manrope, локальные Segoe UI и Arial. Первый экран и карточки компактнее; на desktop в каталоге четыре колонки, на планшете три или две, на телефоне одна. Заголовки используют text-wrap: balance, тексты — text-wrap: pretty; короткие предлоги связаны с последующим словом неразрывным пробелом.

Контакты содержат локальную SVG-схему с улицами, сквером, остановкой, маршрутом во двор и масштабированием 100–180%. Это схема вымышленного адреса, а не географическая карта. Её работа не зависит от внешнего Leaflet CSS. Все перечисленные учебные дефекты сохранены.

## Визуальная концепция студии

Оформление css/studio.css: тёмно-зелёная шапка, терракотовый первый экран, коллаж трёх материалов, графические цветовые блоки и карточки с прямыми углами. Все страницы используют общую визуальную систему. Учебные сетевые сценарии не менялись.

## Карточки и портреты

Портреты вымышленных преподавателей созданы встроенным image_gen, сохранены локально в WebP (около 90–122 КБ). Промпты и происхождение: ASSET-PROMPTS.md. Портреты используются на главной, в списке преподавателей и в профилях. Карточки занятий получили рамку, плашку направления, обозначение длительности, акцент цены и ссылку на занятие всей поверхностью. Общая концепция и учебные дефекты сохранены.
